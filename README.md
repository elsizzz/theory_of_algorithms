# Базовые структуры данных и операции в Python

Данный репозиторий содержит решения практических заданий по основам языка Python: работа со стандартными типами данных, строками, срезами, списками, кортежами, словарями и множествами.

---

## Структура проекта

| Файл | Описание задания | Основные темы |
| :--- | :--- | :--- |
| `00_distance.py` | Расчёт расстояний между городами | Словари, кортежи, вложенные словари, математические формулы |
| `01_circle.py` | Вычисление площади круга и проверка попадания точек | Числа с плавающей точкой, возведение в степень, булева логика |
| `02_operations.py` | Расстановка арифметических знаков и скобок для числа 25 | Арифметические операции, приоритет операторов |
| `03_favorite_movies.py` | Извлечение названий фильмов из строки | Индексация и срезы строк (прямые и отрицательные индексы) |
| `04_my_family.py` | Работа со списком членов семьи и их ростом | Списки, вложенные списки, индексация, функция `sum()` |
| `05_zoo.py` | Моделирование вольеров зоопарка | Методы списков: `insert()`, `extend()`, `remove()`, `index()` |
| `06_songs_list.py` | Подсчёт суммарной длительности композиций Depeche Mode | Списки кортежей, словари, округление `round()` |
| `07_secret_message.py` | Расшифровка секретного сообщения | Сложные срезы строк: шаг, отрицательный шаг, границы |
| `08_garden.py` | Сравнение цветов сада и луга | Множества (`set`), операции: `|`, `&`, `-` |
| `09_shopping.py` | Выбор минимальных цен в магазинах | Вложенные структуры данных, словари |
| `10_store.py` | Расчёт стоимости и остатка товаров на складе | Вложенные словари и списки, агрегация данных |

---

## Требования и запуск

### Требования
* **Python 3.8+**
* Все задания используют исключительно **встроенную стандартную библиотеку Python** (дополнительные сторонние пакеты не требуются).

### Запуск любого скрипта

Клонируйте репозиторий (или скачайте файлы) и запустите нужный скрипт через терминал:

```bash
python3 00_distance.py
python3 01_circle.py
python3 10_store.py
```
